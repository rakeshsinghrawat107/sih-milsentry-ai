## 🛡️ Overview

**MailSentry AI** is India's autonomous, defense-grade **Forensic Email Intelligence Platform** built for national cyber law enforcement. It transforms a raw email into a court-admissible chain-of-custody report in under 0.5 seconds, fully compliant with the **Bharatiya Sakshya Adhiniyam (BSA) 2023 Section 65B**.

> Built for: **CERT-In · I4C 1930 Helpline · National Cyber Crime Reporting Portal · Ministry of Home Affairs**

## ✨ World-Class Features

### 🔬 6-Engine Forensic Stack
| Engine | Description |
|---|---|
| **RFC 5322 Parser** | Header unfold, multipart MIME, base64/QP decode, drag-and-drop .eml |
| **NLP & Stylometry** | 80+ Indian phishing keywords, WormGPT/GenAI burstiness detector, MITRE ATT&CK mapping |
| **Header Auth Engine** | SPF / DKIM / DMARC, Reply-To hijack, display-name spoofing, X-Mailer anomaly |
| **Domain Engine** | 30 protected Indian brands, Cyrillic homoglyphs, Levenshtein lookalike, subdomain impersonation |
| **GeoSpatial + STRAD** | 15-node IP threat DB, Great-Circle distance, speed-of-light physics anomaly detection |
| **Scoring Engine** | 20+ weighted signals, 5-tier threat classification, MITRE ATT&CK mapping |

### 🗺️ Geospatial SMTP Relay Tracer (Leaflet.js)
- Animated relay path from Moscow → Amsterdam → Mumbai
- Interactive hop popups (IP, ISP, Tor/VPN, Abuse Score)
- STRAD Physics Engine: Speed-of-light latency impossibility proof

### 🕸️ Threat Identity Graph (D3.js)
- Force-directed syndicate correlation graph
- Relay chains, Reply-To hijacks, Return-Path divergence nodes
- Hover for IOC intelligence, drag to explore

### ⛓️ BSA 2023 Evidence Vault
- SHA-256 Merkle blockchain for tamper-proof chain of custody
- Verify Ledger — cryptographic integrity check
- Simulate Tampering — live hash divergence demo for judges
- Print judicial E-Panchnama (court-admissible)
- Download `.txt` certificate

### 🚨 National Incident Dispatch
- **CERT-In Section 70B** JSON incident report (copy-to-clipboard)
- **I4C 1930 Helpline** FIR Docket (auto-filled from analysis)
- **Automated Mitigation Playbook** (iptables, Snort/Suricata, BGP Blackhole, DNS Sinkhole, NPCI fund hold)

### 🎵 Tactical Audio Engine
- Web Audio API — zero external assets
- Radar blips, critical fraud klaxons, blockchain seal sounds
- Toggleable mute in topbar
